# 부동산 인스타 카드뉴스 자동화

매일 아침 GitHub이 정부 보도자료(정책·세금)와 뉴스 헤드라인으로 인스타 카드뉴스를 만들고,
아이패드·휴대폰으로 확인 페이지를 보고 **[인스타에 올리기]** 를 누르면 게시돼요. 비용 0원.

처음 설정은 **[설정안내.md](설정안내.md)** 를 순서대로 따라 하세요.

## 원칙
- **정부 보도자료**: 정책브리핑(korea.kr)에서 **공공누리 제1유형**인 것만, 첨부 원문 **글자 그대로** 카드로 나눔(요약·바꿔 쓰기 없음, 표·사진 제외). 출처 표시.
- **신문 기사**: **제목·언론사·날짜·링크만**. 기사 본문·요약문은 쓰지 않음(저작권). 같은 소식의 정부 보도자료가 있으면 그 **보도자료 원문 첫 문장(공공누리 제1유형)**을 '정부 발표 원문' 상자로 붙임(노트북이 올리는 docs/날짜/releases.json 사용).
- **스타 부동산(세트 5)**: GitHub이 기사 제목·링크를 모으고, 노트북(07:00·07:40·12:00)이 **Claude 구독(claude CLI)** 으로 거래 사실만 새 문장으로 정리해 넣음. 기사 문장과 25자 이상 같거나 기사에 없는 숫자가 있으면 넣지 않음. 유료 API 키는 지우고 실행하고, 구독 한도·결제 관련 오류가 나면 바로 멈춤(추가 비용 0원). 범죄·사건 기사는 제외.
- **보도시점(엠바고)** 전에는 올리기 거부. 확정 전 정부안은 "확정 아님" 표시.
- 기본은 **연습 모드**. 실제 게시는 확인 문구 `올립니다` 를 넣어야 동작.
- 인스타는 **공식 API만** 사용(아이디·비밀번호 자동 로그인 없음).

## 매일 흐름
정부 사이트가 해외 서버 접속을 막아서 **노트북 + GitHub** 로 나눠요.
1. 노트북 예약 작업 `CardnewsGovDaily`(07:00·로그인 시) → 정부 보도자료 카드 `docs/날짜/set-1` + `run-gov.json` 올림 → `확인 페이지 갱신` 자동
   GitHub `매일 뉴스 카드 만들기`(07:00 KST) → 뉴스 카드 `set-2` + 확인 페이지
2. 확인 페이지 `https://아이디.github.io/저장소/` 에서 카드·원문 대조·캡션 확인
3. `인스타에 올리기`(수동 실행) → 날짜·세트·모드 입력 → 게시 → 결과가 확인 페이지에

## 확인한 외부 규격 (2026-09-17)
- 정책브리핑 **RSS는 중단됨** → 목록 화면 `/briefing/pressReleaseList.do?repCodeType=정부부처&repCode=코드` 를 읽음
- 부처 코드: 국토교통부 `A00006`, 재정경제부 `A00041`, 국세청 `B00004`, 행정안전부 `A00031` (기획재정부는 재정경제부·기획예산처로 개편됨. 금융위원회는 이 목록에 없음)
- 본문 원문은 첨부 PDF/HWPX에 있고, 페이지에 "텍스트에 한하여 공공누리 제1유형" 표시. 첨부는 **보도시점 전에 먼저 올라옴**
- 인스타: JPEG·8MB 이하·비율 4:5~1.91:1·공개 주소, 캐러셀 최대 10장, 24시간 100건, 토큰 60일(갱신은 24시간 지난 뒤)
- 네이버 뉴스 검색: `https://openapi.naver.com/v1/search/news.json` (열쇠 없으면 401 확인)
